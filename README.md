# kolleranton — родовід Коллерів і Русіних

Агент-генеалог на Claude: шукає родичів у розділі
[«Архів:ДАОО»](https://uk.wikisource.org/wiki/Архів:ДАОО) (Державний архів Одеської області)
на українських Вікіджерелах, записує знахідки в `genealogy/data/tree.json` і генерує сайт
з родовим деревом.

## Що всередині

| Файл | Призначення |
|---|---|
| `genealogy/research.yaml` | Відомі дані про родину та питання для пошуку. **Редагуйте тут.** |
| `genealogy/agent.py` | Агент: шукає по Вікіджерелах (MediaWiki API) і записує людей, факти, зв'язки й справи для замовлення |
| `genealogy/wikisource.py` | Клієнт API uk.wikisource.org (пошук, читання сторінок, пошук у тексті, підсторінки) |
| `genealogy/tree.py` | Сховище дерева (`data/tree.json`) |
| `genealogy/build_site.py` + `site_template.html` | Генератор сайту → `site/index.html` |
| `.github/workflows/genealogy.yml` | Запуск агента й публікація сайту на GitHub Pages |

## Запуск на своєму комп'ютері

```bash
pip install -r genealogy/requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...           # ключ з console.anthropic.com
python genealogy/agent.py                      # пошук (≈ 80 кроків)
python genealogy/agent.py --focus "шлюб Ернеста Коллера і Марії Русіної"
python genealogy/build_site.py                 # сайт у site/index.html
```

Кожен запуск продовжує вже зібране дерево: знахідки накопичуються, дублікати відкидаються.

## Запуск у GitHub (без власного комп'ютера)

1. **Settings → Secrets and variables → Actions** → додайте секрет `ANTHROPIC_API_KEY`.
2. **Settings → Pages → Source: GitHub Actions**.
3. Злийте цю гілку в `main`, потім **Actions → «Родовід — пошук і сайт» → Run workflow**.
   Агент пошукає, закомітить знахідки, а сайт з'явиться за адресою
   `https://kolleranton.github.io/kolleranton/`.

> ⚠️ Репозиторій і сайт GitHub Pages публічні для публічного репозиторію. Якщо родинні дані
> мають бути приватними — зробіть репозиторій приватним (Pages для приватних репозиторіїв
> потребує платного плану) або переглядайте `site/index.html` локально.

## Що реально можна знайти

Вікіджерела з ДАОО — це здебільшого **описи фондів і переліки справ**, а не самі документи.
Тому головний результат агента — розділ сайту **«Справи для замовлення в архіві»**: точні шифри
(фонд / опис / справа) особових справ, актових записів, метричних книг, списків працівників
електростанції тощо. Їх можна замовити в читальному залі ДАОО або запитом на
електронну пошту архіву. Агент позначає непевні збіги як «ймовірно» — перевіряйте їх за оригіналами.

Батьків Ернеста (Вільгельм) та Марії й Зої (Василь) виведено з по батькові — на сайті вони
позначені пунктиром, доки агент не знайде підтвердження.
